# New Engineer Onboarding Checklist

## Week 1
- Laptop, VPN, and MFA set up (see the VPN access policy).
- Accounts: code host, ticket system, incident channel, warehouse read-only.
- Read: incident response guide, deployment rollback runbook, batch failure
  runbook.
- Pair with your onboarding buddy on one real ticket end to end.

## Month 1
- Ship a small change through the full pipeline (build, review, deploy).
- Join the on-call shadow rotation for one week.
- Complete the data-handling and security awareness modules.
- First restore-drill observation (see backup and restore policy).

## Access growth
Production write access is granted after the first month, once the security
modules are complete and your manager approves the access review.
